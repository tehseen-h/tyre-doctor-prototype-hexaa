## M1 — The event engine ✅ done
Both rails ported from `stages.ts`. Append-only `StageEvent[]` per job; `stage` is a derived getter (`events[events.length-1].to`), never a mutable field — confirmed by grep: no code path assigns `job.stage` directly outside the store's own `touch()`. Required-capture gates block advance unless a supervisor override reason is supplied, which is logged on the event (`overrideReason`). Undo is a compensating event (`System — undo`), not a deletion — the original event stays in the log.
**Verified:** walked MKY-TR-26-0417 from Cooked → Final quote sent → Dispatched in the UI, confirmed the toast+undo, and confirmed a blocked-then-overridden advance logs the reason.
